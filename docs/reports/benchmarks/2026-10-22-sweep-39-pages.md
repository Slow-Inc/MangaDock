# 39-page replay sweep — the filter guards lose no dialogue, and what replay can and cannot prove

- **Date:** 2026-10-22 · **Scope:** all 39 corpus pages, `doctor_page.py --replay`, current HEAD vs the `_r2` baseline.
- **Why:** #886's acceptance (and #882/#885) needed a corpus-wide check that the new post-translation guards drop junk without touching real text.

## Method

Per page, compare the **multiset of region source texts** (not indices — any rescued SFX changes the list) and
the drop lists between `_r2` and `_sweep`. Index-based diffing is misleading; a set diff localises the change.

## Result

39/39 pages compared, **16 pages changed, all explained**:

| kind | pages | what changed |
|---|---|---|
| **expected guard drops** | 2 | `Siiig` (letter-name spelling, #882), `月` (art-scale logo glyph, #886) |
| **rescue upgrade** | 1 | Mushoku p0: `을` -> `เคี้ยว` (the vision rescue served this run) |
| **rescue nondeterminism** | 11 | rescued SFX swap between runs (`ฟู่`/`ฟึ่บ`, `วูบ`/`แวบ`, `กึกกัก`/`กริ๊ก`, ...) — a live gateway call inside replay |
| **OCR read micro-variance** | 2 | `CONSIDFR ... IIMF` / `... IIM`, `ZBYTHE` / `7BYTHE` — one junk character in a credit line; from the #884 cuDNN-off numerics |

**No dialogue region was lost on any page** — the only sources that disappeared are the two junk/art drops above.

## What replay cannot prove, and the rule that follows

`--replay` fixes the translations but **still runs the vision SFX rescue live**, so which SFX get localized varies
between runs (11 pages here). Any replay comparison that includes SFX pages must either accept that noise or run
with `--set ocr.vlm_rescue=0`; index-based render diffs on those pages are not evidence of a regression.

The two OCR read variants are the honest cost of #884 (cuDNN-off changes convolution numerics): reads are
identical on the pages measured there, but a junk character can differ elsewhere. It changed no real text.
