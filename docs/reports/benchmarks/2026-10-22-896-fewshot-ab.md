# Thai few-shot sample A/B — the built-in JP→TH sample wins; our eval set is EN→TH

- **Date:** 2026-10-22 · **Issue:** #896 · **Harness:** `tools/translation_ab.py` + chunked pairwise judge.

## Experiment

Arm A: v2 prompt + the built-in Thai sample (JP→TH). Arm B: the same template with an EN→TH sample built from
the judged-audit patterns (stammer/self-correction, cut-off fragment, idiom, name, ordinary dialogue).
12 pages, blinded per page.

| arm | pages won |
|---|---|
| **A = built-in JP→TH sample** | **7** |
| B = EN→TH sample | 5 |

Offline the EN sample repaired the Iruma-1 stammer hallucinations (`I- I DONT WANT THEM.` -> "ฉันท้อง..." in
the base arm vs "ฉันไม่เอาพวกนี้"), but the judge penalised it on the other pages: net negative.

## The caveat worth more than the result

Every translation A/B in this loop runs on **EN→TH** pages (the repo's corpus is English scanlation), while the
production path for Japanese chapters is **JP→TH** — the built-in sample's language. Conclusions about prompts,
samples and temperature therefore measure the EN→TH path and must not be assumed to transfer. A real
**JP→TH evaluation set** is the missing piece before any further translation-tuning work.

## Decision

No code change: the built-in sample stays; the EN arm YAML (`tools/prompts/thai_manga_v2_en_fewshot.yaml`) is
kept as the experiment record. Source-aware sample selection is only worth building with a JP→TH set to prove
the EN half.
