# Quality gate (#990): one deterministic command that re-checks every defect class this loop found

- **Date:** 2026-10-22 · **Issue:** #990 · **Files:** `manga_translator/quality_gate.py`, `tools/quality_gate.py`,
  `test/test_quality_gate.py`.

## What it checks (no model calls)

| check | origin |
|---|---|
| foreign-script leak in a Thai translation | #903 (Cyrillic `ЦУКУโยมิ`) |
| runaway repetition | #901 (4,462-char loop) |
| doubled / leading Thai combining mark | #889 orthography work |
| control / zero-width chars, unexpected Latin words | integrity scans |
| dropped `!` / `?` / `…` (interrobang covers both; `...` covers `…`) | punctuation scan |
| cross-page character-name spellings | #980 glossary metric |

CLI: `tools/quality_gate.py page1.doctor.json [page2.doctor.json …]` — exit 1 on any violation, `--json` for
machine output.

## Why this matters for the loop

The #902 null calibration showed a same-model judge cannot resolve small differences; this gate is the
complementary *hard* signal: it is deterministic, cheap, and re-runnable per chapter. Future rounds can run it
after every replay change and treat a new violation as a regression, without a judge.

## Companion negative results (same round)

Broader deterministic scans over the stored corpus came back clean, which is why no new guard was added:

- punctuation drops: 9 raw hits, all false positives (`…` -> `...`, `?!` -> `⁈`),
- Thai integrity (leading combining marks, doubled marks, control chars) and unexpected Latin: **0 / 11,633**
  stored src/dst pairs.
