# Thai prompt v3 — blind pairwise A/B: v2 wins, v3 rejected (#888)

- **Date:** 2026-10-22 · **Issue:** #888 · **Harness:** `tools/translation_ab.py` (translate -> packet -> judge).
- **Arms:** A = v2 (the shipped `thai_manga_system.txt`), B = v3 (`tools/prompts/thai_manga_v3.yaml`) adding rules
  for the five judged-audit patterns: stammer/hesitation, cut-off fragments, name reading, sense precision,
  self-correction.
- **Sample:** 9 pages — the audit's lowest (Iruma p1, Taida p0, Kage p0, Kumo p1, Otome p1, Tsuki p1) plus
  three controls (Boku p0, Akuyaku p0, Dungeon p0). Both arms translated the same ordered source texts,
  then blinded per page (seeded shuffle) and judged segment-by-segment by the production model.

## Result — keep v2

| | pages won |
|---|---|
| **A = v2** | **6** |
| B = v3 | 2 |
| tie | 1 |

Per page (X/Y are the blinded labels): Akuyaku 8-1 v2, Boku 5-4 v3, Dungeon 3-2 v2, Kage 5-3 v2 (retried),
Kumo tie, Iruma 4-2 v2, Otome 2-1 v2, Taida 3-1 v3, Tsuki 10-5 v2 (retried).

v3 did fix some of the targeted fragments (`AGAI-` -> `ซ้ำ` instead of `อย-อย`, `THEN-` -> `ถ-`), but the
longer rule list made other lines more literal, which the judge penalised overall. No default change.

## Side finding — a real defect the A/B exposed (#889)

Both arms emitted Thai combining marks in a non-canonical order — a tone mark before its above-vowel:
`ท่ี` (should be `ที่`), `น้ี` (should be `นี้`). v2 arm: 1 segment in 9 pages; v3 arm: 3. No shaper can render
the reversed order, so the word is visibly mangled. Fixed deterministically in #889
(`translation_quality.normalize_thai_marks`, wired into `_clean_translation_output`): both arms normalise to
0 invalid sequences and the 372-segment corpus dump is byte-identical (no false rewrites).
