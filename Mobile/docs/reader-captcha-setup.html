MANGADOCK · คู่มือตั้งค่าจริง · 2026-10-05

เปิดหน้าตรวจสอบก่อนเริ่มอ่าน

แอปเปิดหน้า HTTPS เพื่อรับผลจาก Turnstile แล้วกลับเข้าแอป Backend เดิมตรวจผลและออกสิทธิ์อ่าน หน้าเว็บนี้ใช้ไฟล์ที่มีอยู่แล้วใน Mobile/captcha/

URL และ key ด้านล่างเป็นตัวอย่าง ต้องแทนด้วยค่าจริง Cloudflare MCP เป็นเครื่องมือเชื่อมต่อ ไม่ใช่ URL หน้าตรวจสอบ

1. เลือก Turnstile widget เดิม

เปิด Cloudflare Dashboard → Turnstile เลือก widget ที่มี Site key ตรงกับ NEXT_PUBLIC_TURNSTILE_SITE_KEY ใน Frontend/.env และตรวจว่า Secret key ของ widget เดียวกันอยู่ใน Backend/.env เป็น TURNSTILE_SECRET_KEY ใช้คู่เดิมเพื่อให้ Backend ตรวจ token ได้ ไม่ต้องส่ง secret ในแชต

2. ตั้ง public site key ของหน้าตรวจ

เปิด Mobile/captcha/config.js คัดลอกค่าของ NEXT_PUBLIC_TURNSTILE_SITE_KEY มาใส่เฉพาะค่า Site key:

window.MANGADOCK_CAPTCHA_SITE_KEY = 'SITE_KEY_จริงของคุณ';

Site key ใช้ในหน้าเว็บ ส่วน Secret key คงอยู่ที่ Backend

3. เผยแพร่หน้าเว็บบน Cloudflare Pages

Dashboard → Workers & Pages → Create application → Pages / Get started → Drag and drop your files ตั้งชื่อโครงการ เช่น mangadock-captcha แล้วอัปโหลดโฟลเดอร์ Mobile/captcha โดยให้ไฟล์สามไฟล์ต่อไปนี้อยู่ที่ root ของเว็บ:

index.html
config.js
protocol.mjs

เลือก Deploy site แล้วคัดลอก URL production ที่ Cloudflare ให้จริง ตัวอย่าง https://mangadock-captcha.pages.dev ชื่อจริงอาจต่างจากตัวอย่าง

4. อนุญาต hostname ใน Turnstile

กลับไป widget เดิม → Settings → Hostname Management → Add Hostnames เพิ่มเฉพาะ hostname ของ production เช่น:

mangadock-captcha.pages.dev

ใช้ชื่อจริงจากขั้น 3 โดยไม่ใส่ https://, port หรือ /index.html คง hostnames เว็บเดิมทั้งหมด

5. ตั้ง URL ใน Mobile

เพิ่มใน Mobile/.env โดยใช้ URL ของ production ที่ได้จริง:

EXPO_PUBLIC_CAPTCHA_URL=https://mangadock-captcha.pages.dev/index.html

Mobile อ่าน env ของตัวเอง จึงต้องตั้งค่านี้แม้ Frontend มี key แล้ว

6. โหลดค่าใหม่และลองจากแอป

หยุด Metro เดิมด้วย Ctrl+C รันในโฟลเดอร์ Mobile:

npm.cmd run start -- --clear

Reload แอป development ที่ต่อ Metro เปิดตอน → เปิดการตรวจสอบ → ทำ Turnstile → กดกลับไป MangaDock ควรกลับมาโหลดหน้าอ่านผ่าน Backend ที่กำลังทำงานอยู่ แอป release ที่ bundle JS ไว้ต้อง build ใหม่เมื่อเปลี่ยน public env

ตรวจอาการหากยังไม่ผ่าน

เปิดหน้าตรวจสอบไม่ได้ในแอป: ตรวจ Mobile env และ reload JS หน้าเว็บบอกไม่พบคำขอ: เปิดใหม่จากแอป เพราะแอปต้องสร้าง state ของคำขอ widget ไม่ขึ้น: ตรวจ config.js ที่ deploy แล้วและ hostname กลับเข้าแอปแล้วตรวจไม่ผ่าน: ตรวจคู่ key และข้อความตอบจาก Backend

การเปิด URL โดยตรงไม่ได้ยืนยัน flow ทั้งหมด เพราะยังไม่มีคำขอจากแอป หากเปลี่ยน config.js หลัง deploy ต้องอัปโหลด deployment ใหม่
