1. Keep this computer and the phone on the same Wi-Fi. Keep Backend running on port 4001. The current computer Wi-Fi address is `192.168.1.29`; a future address change requires a matching build or an intentionally configured reachable endpoint.
2. On the phone, open `http://192.168.1.29:4001/status`. It must return a Backend JSON response before app connection can be evaluated. This was checked from the computer, not yet from the phone. If unreachable, check Wi-Fi client isolation/VPN/firewall first; no firewall settings were changed automatically.
3. Download the named APK from the local artifact server once the verified file is available, or copy it by USB. Allow installation from the browser/file manager when Android requests it, then install. Do not uninstall the existing primary app to work around a signature mismatch; report the mismatch instead.
4. Open MangaDock without Metro. Test email/provider login and return, cold relaunch/session restoration, search/detail, CAPTCHA and reading. Check page/chapter changes, zoom, reading modes and history.
