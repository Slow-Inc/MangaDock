## What to build

Migrate currently available staff content queues, reports, and moderation actions for Community/reader/Studio content into native role-gated screens, preserving existing state transitions and audit behavior.

Scope: Mobile only; reuse existing APIs, business rules and data. Preserve Frontend/Backend/MIT and the shared bridge.

TDD: One observable behavior through public interfaces at a time, using real Mobile code with external-boundary mocks. Record RED → GREEN; refactor only while GREEN. Release-only work verifies device evidence.

## Acceptance criteria

- [ ] Supported queue/report detail and moderation actions are inventoried and executed against existing APIs.
- [ ] Role restrictions, content status transitions, repeated actions, and server errors are represented accurately.
- [ ] Content/report/moderation permission and state-transition behavior tests pass.
- [ ] Port the existing Frontend responsive mobile design and navigation using DESIGN.md tokens and original artwork; compare corresponding native/web mobile screens.
