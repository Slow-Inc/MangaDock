## What to build

Browse existing Community feeds/categories/trending/manga discussions, open a post, and navigate its author/content references into native screens using the current public/authenticated API behavior.

Scope: Mobile only; reuse existing APIs, business rules and data. Preserve Frontend/Backend/MIT and the shared bridge.

TDD: One observable behavior through public interfaces at a time, using real Mobile code with external-boundary mocks. Record RED → GREEN; refactor only while GREEN. Release-only work verifies device evidence.

- [ ] Existing Community browsing entry points and post details use real existing data and preserve pagination/category identity.
- [ ] Restricted/removed/empty/error states follow current API responses with native back navigation.
- [ ] Community browsing/navigation behavior tests pass.
- [ ] Port the existing Frontend responsive mobile design and navigation using DESIGN.md tokens and original artwork; compare corresponding native/web mobile screens.
