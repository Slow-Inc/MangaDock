## What to build

Open the existing creator's Studio works, select a manga, and manage currently supported draft/version metadata, language, and pricing through native screens and existing role-gated APIs.

Scope: Mobile only; reuse existing APIs, business rules and data. Preserve Frontend/Backend/MIT and the shared bridge.

TDD: One observable behavior through public interfaces at a time, using real Mobile code with external-boundary mocks. Record RED → GREEN; refactor only while GREEN. Release-only work verifies device evidence.

## Acceptance criteria

- [ ] Authorized creators list their works and create/read/edit supported draft/version data using existing contracts.
- [ ] Non-owner/unauthorized/invalid-data responses are enforced and drafts do not appear as public published Chapters.
- [ ] Creator workspace/metadata/price/permission behavior tests pass.
- [ ] Port the existing Frontend responsive mobile design and navigation using DESIGN.md tokens and original artwork; compare corresponding native/web mobile screens.
